# 验机指南

商家难免也会发错货，电脑也可能有次品，因此在收到电脑的快递时候建议做一次验机，以避免后续麻烦。

> 上面的视频是当时录制的经典入门视频，新机型流程基本一致，可放心参考。

## 基本设置

1. 把浏览器、QQ、微信等软件的下载/数据存放位置改到非 C 盘，避免系统盘被撑满。
2. 设计好各种文件夹，例如文档、下载、课程资料、项目等，养成分类习惯。
3. 重要文件开启网盘同步，重要资料多一份备份。
4. 装好常用软件，并到官网更新对应的驱动（如 NVIDIA/AMD 显卡驱动、厂商控制中心）。
5. 检查 Windows 安全中心是否正常、是否需要开启 BitLocker 磁盘加密（结合自己的需求）。
6. 关闭不需要的开机自启项，保持开机速度。
7. 更新系统到最新稳定版，并设置好自动更新策略。
8. 有条件的话先多测试几天，确认没有蓝屏、键盘/屏幕/接口异常等问题。
